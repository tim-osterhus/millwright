# Contributing

Millwright is in a pre-alpha source-validation phase and does not yet have a
general contribution workflow. Please open a focused issue before preparing a
substantial change.

Do not submit Prime Agent pull requests or support requests to this repository.
Upstream-originating defects should be reported to the relevant upstream
project unless they concern Millwright's downstream modifications.

Any contribution must preserve the license and provenance boundary documented
in `UPSTREAM.md` and `THIRD_PARTY_NOTICES.md`.
